개인정보

magomap은 지도를 쓰는 데 필요한 것만 저장해요.

저장하는 것

  • 카카오 사용자 ID와 닉네임 (로그인용)
  • 저장한 장소, 리스트, 방문 메모, 링크
  • 장소의 이전 위치 기록
  • 로그인 세션 (토큰은 해시로만 저장)

지우는 방법

앱에서 계정 → 계정 삭제를 누르면 서버와 이 기기에서 내 데이터가 지워져요. 카카오맵과 카카오 계정은 그대로예요.

추적하지 않아요

이 소개 페이지에는 추적, 분석 도구, 쿠키가 없어요.

magomap은 개인이 만든 독립 프로젝트예요. 카카오와는 관련이 없어요.

코드는 GitHub에 있어요.
