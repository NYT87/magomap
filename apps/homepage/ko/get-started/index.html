시작하기

  1. 카카오로 로그인

    magomap을 열고 ‘카카오로 로그인’을 눌러요. 지금은 초대받은 계정만 쓸 수 있어요.

  2. kakao-list로 가져오기

    먼저 kakao-list 확장 프로그램으로 카카오맵 리스트를 가져와요. 그다음 magomap의 ‘가져오기’ 탭에서 ‘카카오에서 가져오기’를 누르면 돼요. 다시 가져와도 여기 쓴 메모는 그대로예요.

  3. 홈 화면에 추가 (iPhone)

    Safari에서 magomap을 열고 공유 버튼 → ‘홈 화면에 추가’를 눌러요.

  4. 홈 화면에 추가 (Android)

    Chrome에서 magomap을 열고 메뉴 → ‘앱 설치’ 또는 ‘홈 화면에 추가’를 눌러요.

magomap 열기

magomap은 개인이 만든 독립 프로젝트예요. 카카오와는 관련이 없어요.

코드는 GitHub에 있어요.
