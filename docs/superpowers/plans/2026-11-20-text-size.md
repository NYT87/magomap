# Text that follows the device's text size — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Each task follows `docs/superpowers/build-process.md` (builder → gate → reviewers).

**Goal:** Every text size in the web app follows the device's text size (iPhone Text Size via `-apple-system-body`, other browsers' default font size), capped at a 32px base, and layouts stretch instead of clipping.

**Architecture:**
- `apps/web/src/styles/tokens.css` gets one capped base `--text-base: min(1rem, 32px)` and a scale of text tokens derived from it; `html` takes the device size (`100%`, or `-apple-system-body` on Safari).
- Every `font-size` in `apps/web/src/styles/app.css` uses a text token instead of px.
- Boxes that hold text switch fixed `height`/`width` to minimums; the phone search bar and map-button column share one flex column so the buttons always start below the search bar.

**Tech Stack:** plain CSS custom properties, React 19 (one JSX wrapper in MapScreen), Vitest, Playwright (projects `phone` 390×844 and `desktop`).

**Spec:** `docs/superpowers/specs/2026-11-20-text-size-design.md`

## Global Constraints

- **Cap:** `--text-base: min(1rem, 32px)`; one place sets it; no `font-size` bypasses it.
- **Default unchanged:** at a 16px root every text size computes to exactly today's px value.
- **iPhone:** `html { font: -apple-system-body }` only inside `@supports (font: -apple-system-body)`; `body` keeps `font-family: var(--font-body)` and line-height 1.6.
- **Stays px:** spacing, radii, icon sizes, map pins/clusters, map providers' controls, `--mm-tools-width: 64px`, the 44px sync icon, the sync count badge (`.mm-sync__count` incl. its line-height) and the refused dot.
- **Tap targets** ≥ 44 × 44 px at every size.
- **Out of scope:** `apps/homepage`.
- **Gate:** `TEST_DATABASE_URL=postgres://magomap:magomap@localhost:5432/magomap_test ./scripts/gate.sh` must PASS. No `@ts-ignore`, `biome-ignore`, `.skip`/`.only`, `as any`; never delete or weaken tests.
- **Protected paths:** `scripts/`, `biome.json`, `tsconfig.base.json`, `docs/superpowers/**` except this plan.
- **Commits:** branch `fix/rem-text`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Korean at the cap:** long Korean place names, notes and list names wrap at spaces (`keep-all`) and never clip or push a control off-screen. (Task 2 e2e runs in Korean too.)
2. **Sheets and dialogs at the cap** (Sync sheet, confirm dialogs, list form): their content scrolls inside the sheet; close/confirm buttons stay reachable. (Task 2.)
3. **The map screen at the cap:** search bar + button column + notes + bottom nav leave ≥ 50% of the viewport height as map. (Task 2.)
4. **Desktop at default:** nothing moves; the side panel width isn't changed. (Task 1 default-size e2e runs in both projects.)
5. **Over the cap (48px root)** gives exactly the same sizes as 32px. (Task 1.)
